## ⚡ Daily habits (the "real dev" checklist)

1. Activate venv: `source .venv/bin/activate`
2. `git pull` (if collaborating)
3. Small commits: `git add`, `git commit -m "feat: ..."` — don't batch
4. Run `ruff format` before every commit
5. Keep functions under ~30 lines; if it grows, split it
6. Keep files focused — one clear responsibility per file
7. Config via env vars, never hardcode secrets
8. When pasting code (from Stack Overflow or an AI): ask "does this belong in routes, services, or a new file?"
